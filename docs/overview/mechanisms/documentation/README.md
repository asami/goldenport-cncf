# Documentation Management Mechanism Overview

`overview.svg` is the primary at-a-glance view of the Phase 53 documentation
management mechanism.

It distinguishes two ownership paths:

- Component-specific knowledge remains owned by each Component and is embedded
  in the execution Component or resolved from its Documentation Component.
- Shared CNCF/CML/Cozy/SmartDox knowledge is published from framework-owned
  sources to SimpleModeling.org and, when physical distribution is required, a
  framework Documentation Component.

The same overview shows the Help, direct manifest, Textus CBD Support, and
Textus BoK access paths. Public AI Directive guidance and Skill Catalog entries
are information projections only; they do not replace the mounted directive or
install, activate, execute, configure, or authorize a Skill.

specification, and Executable Specifications become authoritative when the
