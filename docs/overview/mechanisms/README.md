# CNCF Mechanism Overviews

Mechanism graphics show how a reusable CNCF facility works, which boundaries it
uses, and which parts are available, partial, planned, or deprecated.

Each graphic should remain compact enough to communicate the current stable
implementation at a glance and should name its design/specification evidence.

Current graphics:

- `documentation/overview.svg`: planned Phase 52 documentation ownership,
  projection, distribution, Help, and AI knowledge routes.
- `jobs/overview.svg`: complete Job management mechanism overview.
- `jobs/job-engine-runtime.svg`: submission, scheduling, Task execution, and
  terminal recording.
- `jobs/job-control-inspection.svg`: authorization, control, inspection,
  projection, and lifecycle Event surfaces.
- `rules/overview.svg`: complete Rule mechanism overview.
- `rules/rule-engine.svg`: pure, provider-neutral Rule Engine evaluation.
- `rules/component-rule-integration.svg`: Component Framework activation,
  outcome binding, and optional ActionPlan admission.
