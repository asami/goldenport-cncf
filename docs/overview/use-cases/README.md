# CNCF Use Case Overviews

Use-case graphics show how a developer goal is realized by combining CNCF
mechanisms. Each graphic should link its mechanism dependencies and distinguish
available behavior from planned or deferred behavior.

Current graphics:

- `jobs/overview.svg`: complete Job management use-case overview.
- `jobs/managed-synchronous-command.svg`: tracked synchronous `JobSync`
  execution.
- `jobs/managed-asynchronous-command.svg`: scheduled `JobAsync` execution.
- `jobs/synchronous-primary-async-continuation.svg`: `JobSyncWithAsyncCont`
  primary and residual execution in one Job.
- `rules/overview.svg`: complete Rule use-case overview.
- `rules/application-rule-evaluation.svg`: available explicit evaluation from
  application logic.
- `rules/lifecycle-rule-constraint.svg`: partial lifecycle-bound Constraint
  path.
- `rules/monitored-condition-event.svg`: partial monitor-to-Event path.
