# Withdrawn Application Capability Package Proposal

Status: withdrawn on 2026-10-15; historical pointer only, no normative contract

The earlier proposal incorrectly introduced an Application-owned package for
Component review metadata. It is replaced by the
[Component Usage Capability package contract](component-usage-capability-package.md).
The owner is the reviewed Component; Application remains reserved for the
Application Model/Tier contrasted with Domain.

`applicationPackage`, `meta/application-capability/` and the old Application ABI
are not supported alternatives. This pointer preserves document history only;
it does not require a compatibility alias, reader, converter or implementation.
