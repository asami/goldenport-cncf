# Phase 64.1 Scope Reduction and Advanced Recovery Deferral

Date: 2026-09-20
Status: superseded critical-path decision; retained as planning history

> The Phase 64.1 local atomic scope was subsequently found to overlap the
> completed Phase 63.1 atomic-execution contract. Phase 64.1 is no longer on
> the `sm-workflow` Phase 1 critical path; Phase 64.2 consumes Phase 63.1
> directly. See [Phase 64/77 Critical-Path Reconciliation](2026-09-20-phase-64-77-critical-path-reconciliation.md).

sm-workflow Phase 1 の completion line を executable specification としたため、CNCF の critical path に 2PC / compensation / durable business recovery を含める必要はないと判断した。

Phase 64.1 は local UnitOfWork atomic execution foundation に縮小する。必要なのは stable UnitOfWorkId、local commit-or-complete-rollback、rolled-back attempt が CommittedTransition を公開しないこと、および Phase 64.2 が deterministic test/runtime path を構築できる structured outcome である。

Phase 64.2 は Phase 64.1 の local atomic foundation を使って ExecProgram / planner / test interpreter / production alignment を構築する。2PC、compensation planning/execution、RecoveryRequired は acceptance から外す。

高度機能は新規 Phase 85 Advanced Transaction, Compensation, and Recovery Runtime に移す。Phase 85 は Phase 77 および sm-workflow Phase 1 の前提ではない。

critical path:

```text
Phase 63
  -> Phase 64
  -> Phase 64.1 local atomic foundation
  -> Phase 64.2 program/interpreter/testability
  -> Phase 77
  -> sm-workflow Phase 1 executable specification

Phase 85 advanced transaction/recovery
  -> later / independently schedulable
```

Phase 64.1 を完全に消すのではなく、64.2 が必要とする最小 atomic failure semantics を明示的に所有させることで、責務と依存関係を単純化する。
