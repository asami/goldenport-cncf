## Scope

- Define typed framework product/version, canonical URL, publication generation,
  document/section identity, digest, and local/installed/cached/online/unavailable
  reference evidence independently from Component resource identity.
- Define generated-from evidence and deterministic stale-projection detection
  from caller-supplied source identity/digest, without reading resources or
  creating another resolver.
- Define framework Documentation Component references as optional publication
  snapshots with no execution dependency or independent authoring authority.
- Extend the deterministic codec, validation, and hostile-input executable
  specifications only for this framework-context boundary.

read-only consumer interface, publication generation, Help, CBD Support, BoK,
and Phase 60 behavior are out of scope.
