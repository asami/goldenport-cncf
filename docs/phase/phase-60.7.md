## Scope

- Project the common view model through Web, HTTP, CLI, and machine-readable surfaces.
- Cover standalone, multi-user, multi-version, multi-instance, and Subsystem contexts.
- Verify declared admin-page discovery, redaction, disclosure, path safety,
  integrity, authorization, hostile metadata/resource handling, and downstream
  acceptance.
